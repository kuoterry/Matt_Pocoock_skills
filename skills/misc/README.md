# Misc

留著但很少用的工具 —— 沒有在 plugin 裡上架。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** —— 設定 Claude Code hook,在危險的 git 指令(push、reset --hard、clean 等)執行前擋下來。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** —— 把測試檔案從 `as` type assertion 遷移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** —— 建立含 section、problem、solution、explainer 的練習題資料夾結構。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** —— 設定 Husky pre-commit hook,搭配 lint-staged、Prettier、型別檢查與測試。
